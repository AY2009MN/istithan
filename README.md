# الاستئذان

نموذج استئذان معلمين (A4) قابل للتعبئة والطباعة والتصدير PDF/صورة. يعمل بدون خادم وبدون إنترنت (PWA).

## التشغيل
- محلياً: `python3 -m http.server` ثم افتح المتصفح (الـ PWA تحتاج http لا file).
- أو فعّل GitHub Pages: Settings ← Pages ← Branch.

## الهيكل (كل ملف خلية مستقلة)
| الملف | المسؤولية |
|---|---|
| `js/main.js` | الربط بين الخلايا فقط |
| `js/grid.js` | بناء الجداول |
| `js/form.js` | قراءة/كتابة الحقول |
| `js/store.js` | التخزين المحلي |
| الختم | سطران يُكتبان بنفس النموذج، بثلاثة ألوان زرقاء |
| `js/share.js` · `js/pdf.js` | التصوير والمشاركة وكتابة PDF |
| `js/fit.js` | ملاءمة العرض للشاشة |
| `sw.js` | العمل دون إنترنت (غيّر `CACHE` عند أي تعديل) |

## الأمان والخصوصية
- البيانات تبقى في متصفح المستخدم فقط.
- CSP صارمة تمنع أي سكربت أو اتصال خارجي.
- `js/vendor/html2canvas.min.js` مكتبة طرف ثالث مضمّنة محلياً (لا CDN).
