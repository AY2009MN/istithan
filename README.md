# الاستئذان

نموذج استئذان معلمين (A4) قابل للتعبئة والطباعة والتصدير PDF/صورة. يعمل بدون خادم وبدون إنترنت (PWA).

## التشغيل
- محلياً: `python3 -m http.server` ثم افتح المتصفح (الـ PWA تحتاج http لا file).
- أو فعّل GitHub Pages: Settings ← Pages ← Branch.

## الهيكل (كل ملف خلية مستقلة)
| الملف | المسؤولية |
|---|---|
| `js/main.js` | الربط بين الخلايا فقط |
| `js/grid.js` | بناء الجداول |
| `js/form.js` | قراءة/كتابة الحقول |
| `js/store.js` | التخزين المحلي |
| الختم | سطران يُكتبان بنفس النموذج، بثلاثة ألوان زرقاء |
| `js/share.js` · `js/pdf.js` | التصوير والمشاركة وكتابة PDF |
| `js/fit.js` | ملاءمة العرض للشاشة |
| `sw.js` | العمل دون إنترنت (غيّر `CACHE` عند أي تعديل) |

## الأمان والخصوصية
- البيانات تبقى في متصفح المستخدم فقط.
- CSP صارمة تمنع أي سكربت أو اتصال خارجي.
- `js/vendor/html2canvas.min.js` مكتبة طرف ثالث مضمّنة محلياً (لا CDN).

## القالب والطباعة (2026-10-26)
- الورقة بنصف صفحة A4: 200×138.5mm بهامش 5mm من كل جهة، وتطبع في النصف الأعلى من A4 عمودي (`@page` بلا هوامش، والهامش داخل الورقة نفسها)، وملف PDF بصفحة A4 عمودية تقع الورقة في نصفها الأعلى.
- الترتيب: شعار الوزارة أعلى اليمين، العنوان وسطًا، شعار المدرسة أعلى اليسار؛ اليوم والتاريخ؛ اسم المعلم والرقم المدني (12 مربعًا)؛ جدول المعلم؛ المراقبة اليومية؛ ثلاثة توقيعات (المعلم، رئيس القسم، يعتمد من المدير/المساعد).
- حقلان اختياريان بزر تفعيل في صفحة الإدخال (مطفآن افتراضيًا، ويُحفظ اختيارك على الجهاز): **سبب الاستئذان** يظهر أعلى الجدول فقط، و**نوع الاستئذان** (تكليف/رسمي) يظهر بجانب المراقبة اليومية. عند إيقاف الزر يختفي الحقل من الورقة.
- عند أي تعديل: غيّر `CACHE` في `sw.js`.
